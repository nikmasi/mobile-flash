# Mobile Flash

A React Native mobile app for creating and studying flashcards.  


## Features

- Create, edit, and delete flashcards
- Organize flashcards into decks
- Track study progress for each card
- Dark mode support
- Local SQLite database for offline usage

## Tech Stack

- **Framework:** React Native  
- **Navigation:** Expo Router  
- **Database:** Expo SQLite  
- **UI Components:** React Native, Custom Components  
- **State Management:** React Hooks
